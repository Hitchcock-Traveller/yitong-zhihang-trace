## 技术说明

两个页面都是单文件 HTML，样式与脚本内联，不依赖外部 CDN、字体或图片服务。溯源档案中的图表以 base64 内嵌，离线打开也能完整显示。

页面为纯静态产物，可直接在浏览器打开，也可用任意静态托管服务发布。
